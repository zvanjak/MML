# Statistics datasets

## Palmer Penguins

`palmer_penguins.csv` is the simplified Palmer Penguins dataset from the
[`palmerpenguins`](https://allisonhorst.github.io/palmerpenguins/) project.

- Authors: Allison Marie Horst, Alison Presmanes Hill, and Kristen B. Gorman
- Source: https://github.com/allisonhorst/palmerpenguins/blob/main/inst/extdata/penguins.csv
- DOI: https://doi.org/10.5281/zenodo.3960218
- License: CC0
- Observations: 344 penguins from three species and three islands in the Palmer Archipelago, Antarctica

The measurements were collected and made available by Dr. Kristen Gorman and the
Palmer Station Long Term Ecological Research program. The file is kept unchanged
from the canonical package source so examples exercise missing-value handling.
